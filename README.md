# Verk.Övn
Detta är en övning i Introduktion till modern utvecklarroll där jag tränar på filsystem, terminal, Git och Github. Jag skapar mappar och filer med terminalen, versionshanterar dem med Git och dokumenterar arbetet i denna README.


# Git-kommandon
git init - skapar et repo
git status - visar vilka filer som ändrats
git add - lägger till filändringar för nästa commit
git commit -m "meddelande" - skapar en version i historiken
git log - visar tidigare commits
git remote - hanterar repo på git-servern
git branch - hanterar branches
git push - skickar upp branch till git-servern
git pull - hämtar branch från git-servern

# Vad är ett repositary, commit och versionshistorik?
Ett repo är en mapp som Git versionshanterar. En commit är en sparad version av filerna vid en viss tidpunkt. Versionshistorik är listan av alla commits, så man kan se och gå tillbaka till tidigare versioner.
